# lumenOS

my own operating system that runs in a browser tab. one html file, zero
frameworks, zero build steps — open `index.html` and it boots.

## apps

- **about.txt** — hello world
- **notes** — autosaves to your browser as you type
- **terminal** — try `help`, `neofetch`, `open music`
- **music** — lo-fi tracks synthesized live with WebAudio (no files!) + visualizer
- **links** — glass cards
- **settings** — wallpapers, accent colors, factory reset

## extras

- dynamic island in the menu bar (toasts + music controls)
- draggable / resizable / minimizable / maximizable glass windows
- dock with running-app dots
- deep-link apps: `index.html#open=terminal,music` or `#island=player`

everything is stored locally in your browser. no accounts, no passwords.
